📡 APP辅助检测

除了物理检测法，你还可以用手机 APP 扫描网络中的可疑设备。这篇攻略教你用几款免费工具辅助排查。

📌 重要提示

这些 APP 只能辅助判断，不能 100% 确定某个设备是偷拍摄像头。看到可疑设备后，仍需要用反光排查法或红外检测法物理确认。

Fing - 网络扫描仪 推荐 iOS / Android 免费

扫描当前 WiFi 网络中的所有连接设备，识别设备类型、厂商、IP 和 MAC 地址。这是最实用的工具。

使用方法：

  1. 连接到你所在房间的 WiFi（酒店/民宿 WiFi）
  2. 打开 Fing，点击"扫描网络"
  3. 查看设备列表，关注以下特征：
    • 制造商名称含 "Camera"、"IPC"、"IP Camera"、"Hikvision"、"Dahua"
    • 设备类型被识别为 "camera" 或 "surveillance"
    • MAC 地址前缀属于监控设备厂商（可搜索 MAC 厂商查询）
    • 设备名称包含中文如"摄像头"、"监控"
  4. 对可疑设备，记录其 IP 地址和 MAC 地址

局限：只能检测通过 WiFi 连接的摄像头，不能检测使用存储卡离线录像的设备。非 WiFi 摄像头（模拟信号、使用 4G 流量卡）也检测不到。

Hidden Camera Detector 辅助 Android 免费

利用手机内置的磁力传感器（磁强计）检测附近的电子设备。所有通电的电子设备都会产生微弱的磁场，摄像头模块的磁场特征尤为明显。

使用方法：

  1. 打开 APP，先远离所有电子设备校准
  2. 将手机背面慢慢靠近可疑位置（距离约 5-10cm）
  3. 观察屏幕上的磁场读数：如果读数突然显著升高（超过基准值 2-3 倍），说明该位置有电子设备
  4. 高读数位置 + 视觉上有小孔 = 高度可疑

局限：任何电子设备（插座、电视、路由器本身）都会引起读数变化。只能告诉你"这里有电子设备"，不能告诉你"这是摄像头"。适合排查装饰品、玩偶等不应该有电子元件的位置。

Network Analyzer 进阶 iOS / Android 免费

比 Fing 更专业的网络分析工具。除了设备扫描外，还支持端口扫描和网络服务发现。

进阶用法：

  • 对 Fing 发现的每个可疑 IP，用 Network Analyzer 扫描其开放端口
  • 摄像头通常开放 RTSP（554端口）、ONVIF（80/8080端口）、HTTP（80端口）
  • 如果某设备开放了 554 或 RTSP 相关端口，极有可能是 IP 摄像头

推荐检测流程

  1. 进门先做：反光排查法（最可靠，5分钟）
  2. 如果房间有 WiFi：打开 Fing 扫描（2分钟，顺便做）
  3. 如果手机支持红外：关灯红外检测（3分钟，多一层保障）
  4. 对可疑位置：用磁力检测仪验证（精准排查）

⚠️ 不要犯的错

  • 只依赖APP不物理检查：离线摄像头 APP 检测不到
  • 看到未知设备就恐慌：酒店的智能电视、空调控制器可能显示为未知设备
  • 擅自拆卸可疑设备：保留证据最重要，拍照后报警
